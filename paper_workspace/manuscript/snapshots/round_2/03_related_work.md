# Related Work {#sec:related}

PaperOEGM sits at the intersection of four research threads: Agent Skill packaging and benchmarking, skill security auditing, automated scientific discovery and paper writing, and fresh-context LLM peer review.

## Agent Skill Packaging and Context Economics

Agent Skills encapsulate domain procedures as Markdown (`SKILL.md`) directories paired with optional scripts and reference files loaded through progressive disclosure [@xu2026agentskills; @destefanis2026gitskills]. Prior work on Agent-Computer Interfaces (ACIs) demonstrated that tool interface design and structured feedback loops strongly govern coding-agent success [@yang2024sweagent]. Large-scale mining of public skill repositories shows that authoring practice lags behind specification intent: @destefanis2026gitskills catalog 3,797,117 `SKILL.md` files (1,877,981 unique contents) across 282,200 GitHub repositories and note the absence of static type checkers or package verifiers. @zhang2026reusable audit 138,133 public skills across 20,556 repositories and find that 91.8% exhibit at least one defect—chiefly packaging bloat, malformed routing metadata, and unstructured reference folders—and confirm on a 20,000-skill startup routing test that specification-compliant metadata improves retrieval accuracy.

Benchmarking utility directly, SkillsBench [@li2026skillsbench] evaluates 87 tasks across 8 domains and 18 model-harness pairs, showing that curated skills increase average pass rates from 33.9% to 50.5% (+16.6 percentage points), while focused, modular skills (at most three modules) consistently outperform larger exhaustive bundles. SkillTester [@wang2026skilltester] similarly combines paired baseline-vs.-with-skill runs with security probes to produce normalized utility and security labels. Closest in packaging philosophy to our system is the public Elephant-Goldfish Model (EGM v0.1.1) [@google2026egm], an open-source multi-harness coding-agent plugin targeting Antigravity, Claude Code, and Codex with fresh-context Goldfish review personas for software design documents. However, EGM does not address research experiment execution safety, quantitative run-to-manuscript provenance, verified citation ledgers, or double-blind LaTeX compilation, and its review workflow relies on a nested `synthesizer` agent that fails on runtimes prohibiting nested subagent spawning. PaperOEGM adapts EGM's multi-harness packaging and fresh-context separation to scientific authoring while enforcing stricter skill size budgets (`<= 12 KB`), flat 1-level dispatch, and a bundled zero-dependency deterministic verifier.

## Skill Security, Prompt Injection, and Supply-Chain Auditing

Because skills blend executable scripts and natural-language instructions, they inherit and amplify Indirect Prompt Injection threats [@greshake2023indirect]. Recent 2026 studies quantify this attack surface systematically. Skill-Inject [@schmotz2026skillinject] evaluates 202 injection-task pairs spanning obvious to subtle context-dependent skill-file attacks and observes up to 80% ASR on frontier LLMs, concluding that neither model scaling nor naive input filtering suffices without context-aware authorization. @saha2026underhood demonstrate `SKILL.md`-only semantic supply-chain attacks on public skill registries that achieve up to 86% retrieval win rate, 77.6% paired-trial selection rate (over a 50% baseline), and 36.5%--100% governance evasion. Surveying the Agent Skills ecosystem, @xu2026agentskills highlight empirical analyses reporting that 26.1% of community-contributed skills contain vulnerabilities, while @badhe2026skillsecurity introduce SkillSec-Eval and evaluate 327 real-world skills across a five-stage lifecycle (repository admission, semantic retrieval, planner selection, execution, and skill evolution). To counter cross-file obfuscation under semantics-preserving rewrites, @lv2026structuredaudit propose SkillGuard-Robust for structured auditing of untrusted skill bundles.

While these works examine general-purpose skill registries, scientific authoring skills introduce domain-specific supply-chain vectors: untrusted conference template archives containing Zip Slip paths or LaTeX `\write18`/`\input{|...}` shell escapes, external literature metadata containing untrusted text, secret leakage into logged bash commands, and accidental author deanonymization via LaTeX `%` comments or PDF `/Author`/`/Creator` metadata. PaperOEGM directly targets these scientific vectors by combining static pre-extraction scanning, paranoid TeX compilation (`openout_any=p`, `--no-shell-escape`), secret redaction in runner manifests, and `pdfinfo` metadata auditing.

## Automated Research and Paper-Writing Systems

End-to-end automated discovery pipelines—including The AI Scientist [@lu2024aiscientist], The AI Scientist-v2 [@yamada2025aiscientistv2], and CycleResearcher [@weng2024cycleresearcher]—automate hypothesis generation, experimentation or iterative research loops, paper drafting, and simulated review using commercial LLM endpoints or post-trained open-weight models. Yet PaperBench [@starace2025paperbench] (20 ICML 2024 Spotlight and Oral papers decomposed into 8,316 rubric items) shows that the strongest tested autonomous agent reaches an average replication score of only 21.0%, underscoring the need for human-in-the-loop checkpoints and rigorous provenance tracking rather than unattended generation.

Decoupling manuscript composition from fixed experimental pipelines, PaperOrchestra [@song2026paperorchestra] transforms unstructured pre-writing research materials into LaTeX manuscripts and visuals via coordinated agents, outperforming autonomous baselines by 50%--68% on literature review and 14%--38% overall quality win margins on the 200-paper PaperWritingBench benchmark. PaperBanana [@zhu2026paperbanana] focuses specifically on automated academic illustration via Vision-Language Models (VLMs) and image-generation refinement. Whereas PaperOrchestra targets post-experiment automated drafting as a standalone multi-agent framework, it does not package interactive pre-experiment skills for coding-agent harnesses, provide a zero-dependency deterministic run-to-manuscript verifier, or enforce double-blind LaTeX supply-chain and archive checks. PaperOEGM complements this literature as a zero-API-key Agent Skills plugin supporting both full research lifecycles (`po-start` through `po-format`) and bring-your-own (BYO) log entry points.

## Self-Correction Limits and Fresh-Context Peer Review

Empirical work on LLM self-refinement shows that intrinsic self-correction without external feedback fails to improve—and can degrade—reasoning accuracy [@huang2024selfcorrect]. Conversely, large-scale peer-review studies indicate substantial utility when LLM critiques are generated independently: analyzing 3,096 Nature-family and 1,709 ICLR papers alongside a 308-researcher user study, @liang2024feedback find that LLM feedback overlaps with human reviewers (30.85% on Nature, 39.23% on ICLR) at rates comparable to inter-human overlap (28.58% and 35.25%), with 57.4% of researchers rating the feedback helpful while noting remaining limitations. PaperOEGM operationalizes these findings directly: deterministic `po_tools.py` supplies reliable external mechanical verification, while five fresh-context read-only critics supply independent semantic review without polluting or mutating the author's drafting workspace.
