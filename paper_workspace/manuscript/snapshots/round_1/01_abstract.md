# Abstract

Packaging complex, multi-stage scientific workflows as reusable Agent Skills (`SKILL.md` packages) exposes three coupled engineering failure modes: prompt context bloat and packaging defects across coding-agent harnesses, unverified provenance drift between experimental logs and manuscript claims, and security or anonymity leaks from untrusted literature sources and external LaTeX templates. Existing automated paper-writing systems rely on external Large Language Model (LLM) API keys, monolithic Python loops, and same-context self-review that cannot reliably self-correct reasoning or verify mechanical artifacts. We present **PaperOEGM**, a zero-API-key, multi-harness Agent Skills plugin that guides researchers from ideas, starter codebases, or bring-your-own (BYO) logs to provenance-checked, venue-formatted LaTeX manuscripts. PaperOEGM separates *deterministic verification* from *semantic critique* across three layers: (1) ten strictly budgeted progressive-disclosure skills (3,466–4,526 bytes each, under 63 lines) guarded by explicit human gates and SHA-256 digest drift tracking; (2) a zero-dependency Python standard-library verifier (`po_tools.py`) enforcing citation snapshots, non-synthetic experiment provenance, inline run-to-metric matching, Markdown-to-LaTeX parity, double-blind hygiene, and template archive safety; and (3) five flat, single-level read-only critic subagents executing in fresh contexts paired with paranoid LaTeX sandboxing. Across four empirical studies, PaperOEGM reduces median per-stage prompt context by 82.16% (97.14% startup index reduction) relative to a monolithic skill while achieving 100.0% deterministic ZIP SHA-256 build parity across Antigravity, Claude Code, and Codex with zero packaging defects; detects 100.0% of 80 fault-injected violations with 0.0% false positives on PO-FaultBench (five seeds, 115.72 ms mean latency) while explicitly exposing 0.0% deterministic recall on 20 semantic and macro-obfuscation evasion cases; scales to 120 citations and 30 runs in 272.48 ms with 87.96% citation context offloading and zero identity leaks across three compiled venues; and recovers 100.0% of planted semantic flaws across three seeded domain manuscripts via 15 live read-only critic invocations with zero workspace mutations.
