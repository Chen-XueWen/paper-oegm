# Related Work {#sec:related}

PaperOEGM intersects four areas: Agent Skill packaging, skill security, automated paper writing, and fresh-context LLM review.

## Agent Skill Packaging and Context Economics

Agent Skills package Markdown (`SKILL.md`) procedures with optional scripts and references loaded via progressive disclosure [@xu2026agentskills; @destefanis2026gitskills], extending Agent-Computer Interface (ACI) insights that structured interfaces govern coding-agent reliability [@yang2024sweagent]. Large-scale audits show weak packaging hygiene: @destefanis2026gitskills catalog 3,797,117 `SKILL.md` files (1,877,981 unique contents) across 282,200 repositories lacking static verifiers, and @zhang2026reusable find 91.8% of 138,133 skills (20,556 repositories) have at least one defect, while confirming on a 20,000-skill test that valid metadata improves startup routing.

On utility, SkillsBench [@li2026skillsbench] (87 tasks, 8 domains, 18 model-harness pairs) shows curated skills raise average pass rates from 33.9% to 50.5% (+16.6 percentage points), with focused skills (at most three modules) outperforming larger exhaustive bundles. SkillTester [@wang2026skilltester] pairs baseline-vs.-with-skill execution with security probes. Closest in packaging philosophy is the open-source Elephant-Goldfish Model (EGM v0.1.1) [@google2026egm], which packages fresh-context Goldfish reviewers across Antigravity, Claude Code, and Codex for software design docs. Unlike PaperOEGM, EGM lacks experiment safety, quantitative provenance, citation ledgers, and LaTeX sandboxing, and relies on a nested `synthesizer` subagent incompatible with non-nesting runtimes.

## Skill Security and Supply-Chain Auditing

Because skills mix natural-language instructions and executable scripts, they amplify Indirect Prompt Injection [@greshake2023indirect]. Skill-Inject [@schmotz2026skillinject] (202 injection-task pairs spanning obvious to subtle context-dependent skill-file attacks) reports up to 80% ASR on frontier LLMs, showing model scaling and naive input filters are insufficient without context-aware authorization. @saha2026underhood demonstrate `SKILL.md`-only semantic supply-chain attacks achieving up to 86% retrieval win rate, 77.6% paired-trial selection rate (over a 50% baseline), and 36.5%--100% governance evasion. Surveying the ecosystem, @xu2026agentskills cite analyses finding 26.1% of community skills vulnerable, while @badhe2026skillsecurity introduce SkillSec-Eval across 327 skills and a five-stage lifecycle (repository admission, semantic retrieval, planner selection, execution, skill evolution); @lv2026structuredaudit propose SkillGuard-Robust for cross-file auditing under semantics-preserving rewrites. Scientific authoring adds domain-specific vectors—untrusted conference LaTeX archives (Zip Slip, `\write18`, `\input{|...}`), secret leaks in experiment logs, and double-blind PDF metadata leaks—which PaperOEGM directly targets.

## Automated Research and Fresh-Context Peer Review

Autonomous discovery pipelines—The AI Scientist [@lu2024aiscientist], The AI Scientist-v2 [@yamada2025aiscientistv2], and CycleResearcher [@weng2024cycleresearcher]—automate research loops and simulated review via external LLM APIs or post-trained weights. Yet PaperBench [@starace2025paperbench] (20 ICML 2024 Spotlight/Oral papers, 8,316 rubric items) shows the strongest autonomous agent achieves only a 21.0% average replication score, reinforcing human-in-the-loop checkpoints. Decoupling writing from fixed pipelines, PaperOrchestra [@song2026paperorchestra] turns unstructured pre-writing materials into LaTeX manuscripts and visuals (+50%--68% literature review and +14%--38% overall win margins on 200-paper PaperWritingBench), while PaperBanana [@zhu2026paperbanana] automates academic illustrations via Vision-Language Models (VLMs) and image generation. However, PaperOrchestra does not package interactive pre-experiment coding-agent skills, a zero-dependency deterministic run-to-manuscript verifier, or double-blind archive/TeX checks.

Finally, @huang2024selfcorrect show LLMs cannot reliably self-correct reasoning without external feedback, whereas @liang2024feedback (3,096 Nature-family and 1,709 ICLR papers; 308 researchers) show independent LLM review matches inter-human overlap (30.85%/39.23% vs. 28.58%/35.25%), with 57.4% finding feedback helpful while noting limitations. PaperOEGM combines deterministic external verification (`po_tools.py`) with five fresh-context read-only critics to capture both advantages without mutating the drafting workspace.
