# Abstract

Packaging multi-stage scientific workflows as reusable Agent Skills (`SKILL.md` packages) exposes three coupled engineering failure modes: prompt context bloat and packaging defects across coding-agent harnesses, unverified provenance drift between experimental logs and manuscript claims, and security or anonymity leaks from untrusted literature records and external LaTeX templates. Existing automated paper-writing systems rely on external Large Language Model (LLM) API keys, monolithic pipelines, or same-context self-review that cannot reliably self-correct reasoning. We present **PaperOEGM**, a zero-API-key Agent Skills plugin spanning Antigravity (live-verified end to end), Claude Code (packaging-validated), and Codex (structurally packaged). PaperOEGM separates *deterministic mechanical verification* from *fresh-context semantic critique* across three layers: (1) ten progressive-disclosure skills (3,466–4,526 bytes each, at most 63 lines) guarded by explicit human gates and SHA-256 digest drift tracking; (2) a zero-dependency Python standard-library verifier (`po_tools.py`) checking citation snapshots, non-synthetic provenance, inline run-to-metric matching, Markdown-to-LaTeX parity, double-blind hygiene, and archive safety; and (3) five flat, single-level read-only critic subagents paired with paranoid LaTeX compilation. Across four empirical studies, PaperOEGM reduces median active-stage prompt context by 82.16% (97.14% startup index reduction) relative to a monolithic baseline while achieving 100.0% deterministic ZIP SHA-256 parity with zero packaging defects. On our author-constructed 120-workspace PO-FaultBench (80 positive faults plus 40 hard negative controls per seed across five seeds), `po_tools.py` achieves 100.0% recall and 0.0% false positives in 108.20 ms/workspace while exposing 0.0% deterministic recall on 20 adversarial evasion cases per seed. Verification scales to 120 citations and 30 runs in 268.55 ms, offloads 87.96% of raw citation metadata from the shared ledger, compiles three double-blind venues with zero identity leaks, and blocks obfuscated shell escapes and parent-directory writes—while uncovering an upstream TeX Live 2026 regression that renders `openin_any=p` a silent no-op. Finally, across three seeded domain manuscripts, 15 live read-only Antigravity critic invocations recover 100.0% of planted semantic flaws missed by deterministic checks with zero workspace mutations.
