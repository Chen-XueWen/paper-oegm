## 1. Core Thesis & Verified Contributions

**Core Thesis:** Packaging an end-to-end academic research-to-paper workflow as composable, zero-API-key agent skills requires separating *deterministic verification* from *semantic scientific critique*—combining strictly budgeted progressive-disclosure skills (`<= 12 KB`), a zero-dependency Python stdlib verifier (`po_tools.py`), paranoid LaTeX sandboxing, and flat 1-level fresh-context read-only critics to prevent provenance drift, context bloat, and supply-chain leaks without external LLM API keys.

1. **Multi-Harness Progressive-Disclosure Skill Architecture (`exp02_packaging_agg`):** Splitting the 10-stage workflow (`po-start` through `po-format`) into modular `SKILL.md` units (`3,466`–`4,526` bytes; median `3,900` bytes; `<= 63` lines) cuts median active-stage context by **`82.16%`** (`14,171` vs. `79,454` bytes monolithic) and startup index load by **`97.14%`** (`2,270` bytes), keeping `81.14%` headroom below Antigravity's `24 KB` ceiling (where the reference Google EGM plugin's largest skill reaches `24,257` bytes), with `0` packaging defects, passing `claude plugin validate`, and **`100.0%`** deterministic ZIP SHA-256 parity across `antigravity`, `claude`, and `openai` in `143.00 ± 10.09 ms`.
2. **Deterministic Provenance, Parity & Supply-Chain Verifier (`exp01_faultbench_agg`, `exp03_scalability_agg`):** Across `PO-FaultBench` (`120` workspaces × `5` seeds: `8` fault families + `40` hard negative controls), `po_tools.py` achieves **`100.0%` recall**, **`100.0%` precision**, and **`0.0%` FPR** (`115.72 ± 6.03 ms`/workspace), outperforming Compiler-Only (`6.25%` recall) and Ablated No-Inline-Provenance (`87.5%` recall). Across `20`–`120` citations and `5`–`30` runs, all 4 CLI subcommands finish in `260.37 ± 8.73 ms` (`S`) to **`272.48 ± 3.99 ms`** (`XL`, only `+12.11 ms` marginal growth across a `6×` scale increase), offloading `literature/sources/` cuts `citation_ledger.json` context by **`87.96%`**, and paranoid compilation (`openin_any=p`, `openout_any=p`, `--no-shell-escape`) succeeds on **`3/3`** venues (`acmart[sigplan]`, `cvpr2025`, `iclr2025`) with **`0`** identity leaks.
3. **Hybrid Fresh-Context Read-Only Review & Honest Boundary Analysis (`exp01_faultbench_agg`, `exp04_hybrid_agg`):** On the `20`-case adversarial/semantic evasion suite (`exp01_faultbench_agg`), deterministic regex/schema verification drops to **`0.0%` recall** (integer-only falsification, `\csname`-obfuscated TeX macros, semantic citation distortion, and prose deanonymization). Across `n=3` seeded domain manuscripts (`30` defects: `15` mechanical + `15` semantic; `15` live read-only critic invocations), deterministic checks recover `100.0%` mechanical / `0.0%` semantic (`50.0%` total), while PaperOEGM's flat parallel read-only critics recover **`100.0%` semantic** (`100.0%` hybrid total) with **`0.0`** clean-control false positives, **`0`** workspace mutations (`check-readonly`), and peak output **`1,411.0 ± 35.68`** tokens (`<= 1,500` budget).
4. **Explicit Negative / Boundary Results Reported:** (a) Deterministic verification fails completely (`0.0%`) on semantic and obfuscated-macro evasions (`exp01_faultbench_agg`), proving native TeX sandboxing and semantic critics are non-optional; (b) 4-subprocess CLI latency at `XL` (`272.48 ms`) slightly exceeded our initial `250 ms` estimate due to Python process startup (`134.18 ms` in `state-sync` alone), though remaining `7.3×` under the `2,000 ms` threshold; (c) `acmart` v2.16 injects a generic non-identifying `Creator: LaTeX with acmart ...` string via `hyperxmp` even with `\hypersetup{pdfcreator={}}` (`pdfinfo_generic_creator_tags = 1`, `pdfinfo_leaks = 0`); (d) live multi-critic evaluation (`exp04`) is scoped to `n=3` compact seeded drafts on Antigravity, and Codex execution remains structurally verified.
