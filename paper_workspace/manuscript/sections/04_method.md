# System Design {#sec:method}

PaperOEGM packages an end-to-end research-to-paper workflow across Antigravity, Claude Code, and Codex around four invariants: (1) budgeted progressive-disclosure skills with human gates, (2) zero-dependency deterministic verification over single-source state, (3) flat single-level read-only peer review, and (4) defense-in-depth build safety.

## Progressive-Disclosure Skill Graph and State Machine {#sec:method-skills}

PaperOEGM decomposes authoring into ten skills under `skills/po-*/SKILL.md` (`po-literature` runs in two passes: Stage 1a early survey and optional Stage 1b late refresh) across three phases (Figure~\ref{fig:architecture}, Layer 1):

* **Phase 1 (Intake & Experiments):** Stage 0 `po-start` (routing, secret denylist, toolchain probe), Stage 1a `po-literature`, Stage 2 `po-exp-design` (falsifiable hypotheses, ablations, metric schema), and Stage 3 `po-exp-code` (safe bash runners, `--dry-run` smoke checks).
* **Phase 2 (Plan & Draft):** Stage 4 `po-outline` (canonical run reconciliation, page budget), Stage 1b `po-literature` (optional), Stage 5 `po-visuals` (code-rendered plots, multimodal audit), and Stage 6 `po-draft` (modular Markdown with inline provenance tags).
* **Phase 3 (Review & Build):** Stage 7 `po-review` (preflight + five flat parallel read-only critics), Stage 8 `po-resolve` (reversible snapshots and three-bucket triage separating mechanical fixes, scientific decisions, and optional polish), and Stage 9 `po-format` (Pandoc export, paranoid LaTeX build, `pdfinfo` hygiene, post-compile PDF layout audit).

Guided by empirical skill-reuse findings [@zhang2026reusable; @li2026skillsbench], every `SKILL.md` is capped at `<= 250` lines and `<= 12,000` bytes (half of Antigravity's observed 24 KB / 24,000-byte skill limit), offloading shared rules into `execution_instructions.md`, six protocols (`resources/protocols/`), and five review standards (`resources/review_standards/`). Every skill declares `disable-model-invocation: true`, blocking unprompted transitions and enforcing single-select human checkpoints. Single-source `paper_state.json` owns title, venue (`name`, `template_year`, `submission_mode`, `page_limit_main`), probed tools, and SHA-256 `input_hashes`/`output_hashes`, regenerating `STATUS.md` atomically on every sync.

Let $B_{\text{mono}}$ be the monolithic sum of all ten `SKILL.md` files, `execution_instructions.md`, six protocols, and five standards; $B_{\text{stage}}(s)$ the active footprint of skill $s$ (`SKILL.md` + `execution_instructions.md` + protocols directly referenced by $s$); and $B_{\text{idx}}$ the combined startup YAML frontmatter index. Per-stage context reduction $R_{\text{ctx}}$ and startup index reduction $R_{\text{idx}}$ are:

$$R_{\text{ctx}} = \left(1 - \frac{\operatorname{median}_{s} B_{\text{stage}}(s)}{B_{\text{mono}}}\right) \times 100\%, \quad R_{\text{idx}} = \left(1 - \frac{B_{\text{idx}}}{B_{\text{mono}}}\right) \times 100\%$$ {#eq:context-reduction}

## Zero-Dependency Deterministic Verifier (`po_tools.py`) {#sec:method-verifier}

To supply zero-stochasticity external verification [@huang2024selfcorrect] without runtime `pip install`, PaperOEGM bundles `resources/scripts/po_tools.py`, a 758-line Python 3.10+ standard-library CLI with four subcommands (Figure~\ref{fig:architecture}, Layer 2):

1. **`state-sync`:** Atomically validates `paper_state.json` (`tmp` + `os.replace`), probes local binaries (`pandoc`, `latexmk`/`pdflatex`, `bibtex`, `pdftoppm`, optional `matplotlib`), counts unresolved `TODO` or pending-run markers, and flags upstream-modified downstream stages `stale`.
2. **`check-readonly`:** Snapshots (`--create`) and verifies (`--verify`) SHA-256 digests of tracked files inside the workspace before and after read-only critic execution, exiting 1 on any added, modified, or deleted file.
3. **`review-preflight`:** Audits mechanical provenance before spawning critics: (i) extracts Pandoc (`[@key]`, `@key`) and LaTeX (`\cite*{key}`) citations across `manuscript/sections/*.md`, enforcing 1:1 parity with `literature/references.bib` and `literature/citation_ledger.json`, blocking `unverified_needs_human_check`, and confirming `verified_source` files exist under `literature/sources/`; (ii) blocks references to the isolated `dry_run/` path, `is_synthetic: true` runs, and unattested `user_byo` runs while flagging `git_dirty: true` as Major; and (iii) parses inline `<!-- run:<run_id> -->` markers, auditing every decimal token $v$ ($d$ fractional digits) in the following paragraph/table block against the flattened numeric set $\mathcal{M}(r)$ of canonical `metrics.json`:

    $$|m - v| \le \epsilon(d) \;\lor\; \Big(0 \le m \le 1 \;\land\; |100m - v| \le \epsilon(d)\Big), \quad \epsilon(d) = 0.55 \times 10^{-d}$$ {#eq:decimal-match}

    where the second disjunct permits $0\text{--}1 \to \%$ scaling strictly for $m \in [0, 1]$ and $\epsilon(d)$ allows standard rounding. Restricting regex matching to decimal tokens (`\d+\.\d+`) avoids false alarms on section or epoch integers, intentionally delegating integer-count auditing, metric-key swapping within unordered $\mathcal{M}(r)$, unit-ambiguous $[0, 1]$ scaling, and untagged paragraphs to `po-evidence-auditor`.

4. **`format-verify`:** Scans `.zip`/`.tar.*` template archives for Zip Slip (`..`, leading `/`), symlinks/hardlinks, and active TeX shell pipes (`\write18`, `\immediate\write18`, `\input{|...}`) after stripping `%` comments; checks `.md`-to-`.tex` citation, `\label{}`, and non-dimension decimal parity (filtering LaTeX units like `0.85\linewidth`, `10.5pt`); parses TeX `.log`/`.aux` telemetry (undefined refs/cites, missing graphics, `Overfull \hbox > 2pt`); and enforces double-blind hygiene across `.tex` body and `%` comments (blocking `/Users/`, `/home/`, `C:\Users\`, GitHub URLs, `\iclrfinalcopy`, `\usepackage{cvpr}`).

## Experiment Safety, Visuals, and Context Offloading {#sec:method-safety}

Stage 3 runners enforce `set -euo pipefail`, double-quoted paths, `WANDB_MODE=offline`, non-git fallback (`git_commit: "none"`, `git_dirty: null`), secret/`$HOME` redaction in logged `cmd`, crash-safe startup `run_manifest.json` + `trap finalize EXIT`, atomic `metrics.json` (`< 10 KB`), and `--dry-run` isolation in `dry_run/<run_id>/` (`is_synthetic: true`).

Stage 1 stores raw primary-source API snapshots in `literature/sources/<citekey>.json` and keeps only compact pointers plus 1--2 sentence summaries in `citation_ledger.json`, giving ledger offload ratio $R_{\text{off}} = (1 - S_{\text{led}} / (S_{\text{led}} + S_{\text{src}})) \times 100\%$ for non-citation stages while `po-citation-auditor` loads snapshots on demand. Stage 5 requires newly generated quantitative plots to load directly from canonical non-synthetic `metrics.json`/`series.csv` via version-controlled Python scripts (optional `matplotlib`, zero hardcoded arrays, zero generative raster tools on data), exporting colorblind-safe dual-encoded vector PDFs with stripped metadata plus high-DPI PNG previews verified visually.

## Flat Critics, Paranoid TeX Sandbox, and Multi-Harness Packaging {#sec:method-critics}

Stage 7 dispatches five stateless read-only personas (`agents/po-*.md`, `<= 6,000` bytes)—`po-peer-reviewer`, `po-evidence-auditor`, `po-citation-auditor`, `po-visual-format-critic` (Pass 1 figures + Pass 2 chunked 4--5 page PDF layout), and `po-clarity-reader`—**flat at depth one in parallel** (Figure~\ref{fig:architecture}, Layer 3a). Unlike EGM's nested `synthesizer` [@google2026egm], flat dispatch avoids nesting failures on Antigravity and Claude Code Cowork, bounds each critic to 1,500 output tokens, and logs a 4-state `Reviewer Status` table (`completed`, `skipped_not_applicable`, `carried_forward`, `not_run`); Claude Code adapters (`.claude-plugin/agents/po-*.md`) restrict `tools:` strictly to `Read, Grep, Glob`.

Because static regexes miss macro-obfuscated TeX escapes (e.g., `\csname write18\endcsname`), Stage 9 wraps compilation with paranoid flags (`openin_any=p openout_any=p pdflatex --no-shell-escape`, where `p` requests paranoid mode disallowing dotfiles and parent directories), strips identity metadata via `\hypersetup{pdfauthor={},pdfcreator={},pdfproducer={}}`, and checks `pdfinfo`. As Section~\ref{sec:exp-rq3} verifies, `--no-shell-escape` and `openout_any=p` hold on TeX Live 2026 while `openin_any=p` became an upstream no-op. Finally, `scripts/pack_plugin.py` synchronizes all five manifests and emits deterministic ZIP bundles (fixed `1980-01-01` timestamps, sorted traversal) across Antigravity, Claude Code, and Codex.
