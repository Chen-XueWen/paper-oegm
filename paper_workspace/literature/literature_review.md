## 1. Thematic Taxonomy

### Axis 1: Agent Skills Ecosystem, Packaging Quality & Compositional Benchmarks
The `SKILL.md` open format packages procedural instructions, helper scripts, and reference documents into progressive-disclosure units loaded on demand across coding harnesses [@xu2026agentskills; @destefanis2026gitskills]. Mining `3,797,117` public `SKILL.md` files (`1,877,981` unique contents across `282,200` repositories), @destefanis2026gitskills observe that natural-language skills lack compilers, type checkers, or centralized package verification. Analyzing `138,133` public skills, @zhang2026reusable report that **91.8%** contain at least one defect—dominated by mundane packaging failures (weak routing metadata, bloated bodies, disorganized resources)—and show via a 20,000-skill routing test that spec-compliant metadata measurably improves startup retrieval. On task efficacy, **SkillsBench** [@li2026skillsbench] evaluates 87 tasks across 8 domains and 18 model-harness configurations, demonstrating that curated skills lift average pass rates from **33.9% to 50.5%** (+16.6 pp) and that **focused, modular skills (<= 3 modules)** outperform bloated exhaustive documentation bundles. Meanwhile, @yang2024sweagent showed how specially designed Agent-Computer Interfaces (ACIs) shape coding-agent performance, and @wang2026skilltester introduced paired utility-and-security evaluation for individual skills. Finally, the **Elephant-Goldfish Model (EGM)** [@google2026egm] pioneered multi-harness plugin packaging (Antigravity, Claude Code, Codex) and fresh-context review personas for engineering design docs, but does not address research experiment execution, quantitative scientific provenance, or flat 1-level dispatch across non-nesting runtimes.

### Axis 2: Automated Scientific Research & Paper-Writing Agents
End-to-end autonomous research systems—including **The AI Scientist** [@lu2024aiscientist], **The AI Scientist-v2** [@yamada2025aiscientistv2], and **CycleResearcher** [@weng2024cycleresearcher]—automate hypothesis generation, execution, drafting, and simulated review inside unattended Python loops backed by external LLM API keys. Yet **PaperBench** [@starace2025paperbench] (20 ICML 2024 Spotlight/Oral papers, 8,316 graded rubric items) shows that frontier autonomous agents still achieve only 21.0% end-to-end replication, far below ML PhDs. Decoupling writing from fixed experiment runners, **PaperOrchestra** [@song2026paperorchestra] converts unstructured pre-writing materials into LaTeX manuscripts (achieving 50%–68% literature review and 14%–38% overall quality win-rate margins over autonomous baselines on 200-paper PaperWritingBench), while **PaperBanana** [@zhu2026paperbanana] automates academic illustrations via VLMs and image generation models. However, PaperOrchestra operates as a monolithic, external-API Python CLI that begins only after experiments finish, lacks deterministic provenance auditing between raw runs and manuscript numbers, relies on generative image loops near quantitative plots, and lacks cross-harness Agent Skill packaging.

### Axis 3: Agent Skill Security, Supply-Chain Risks & Indirect Prompt Injection
Building on Indirect Prompt Injection [@greshake2023indirect], recent 2026 studies demonstrate severe security gaps in Agent Skills. **Skill-Inject** [@schmotz2026skillinject] (202 injection-task pairs) finds frontier LLMs exhibit up to **80% attack success rate (ASR)** on context-dependent skill-file attacks (data exfiltration, destructive routines), concluding that model scaling and naive input filters are insufficient without context-aware authorization. @saha2026underhood show `SKILL.md`-only semantic supply-chain attacks manipulate discovery (up to 86% win rate), selection (77.6% bias), and governance evasion (36.5%–100%). Lifecycle evaluations [@badhe2026skillsecurity; @xu2026agentskills] document high vulnerability rates across community registries (`26.1%` reported in @xu2026agentskills), motivating structured cross-file auditing such as **SkillGuard-Robust** [@lv2026structuredaudit]. Notably, none of these defenses target the domain-specific attack surfaces of scientific authoring skills: untrusted external LaTeX templates (Zip Slip, `\write18`, `\openin`/`\openout`), double-blind PDF metadata/`%`-comment leaks, secret leakage into experiment manifests, or prompt injection via scraped web abstracts and local PDFs.

### Axis 4: Self-Correction Limits & Fresh-Context Automated Peer Review
@huang2024selfcorrect show that LLMs cannot reliably perform intrinsic self-correction on reasoning without external feedback—and can degrade initially correct answers—exposing the risk of same-context self-review in monolithic writing loops. Conversely, large-scale analysis by @liang2024feedback (`3,096` Nature + `1,709` ICLR papers; `308`-researcher user study) shows LLM paper-review overlap with human reviewers (`30.85%` Nature, `39.23%` ICLR) matches inter-human overlap (`28.58%` / `35.25%`), with `57.4%` of researchers finding feedback helpful while highlighting factual verification limits. Pairing deterministic external verification (`po_tools.py`) with isolated, fresh-context read-only critics directly addresses both intrinsic self-correction bias and factual audit gaps.

## 3. Concrete Research Gaps Motivating Stage 2 (`po-exp-design`)

1. **Gap 1 — Modular Skill Packaging vs. Real-World Defect Rates:** @zhang2026reusable find 91.8% of public skills have packaging/metadata defects and @li2026skillsbench show focused modular skills outperform monolithic bundles, yet few real-world complex multi-stage systems empirically quantify skill load-size budgets, cross-harness manifest parity, and automated invariant enforcement across Antigravity, Claude Code, and Codex.
2. **Gap 2 — Deterministic Verifier + Fresh-Context Critic Separation vs. LLM-Only & Self-Review:** @huang2024selfcorrect and @schmotz2026skillinject show pure LLM prompting fails on intrinsic self-correction and adversarial/subtle compliance. We need controlled quantitative fault-injection experiments measuring detection recall, precision, and false-positive rates of:
   * (a) **Deterministic verifier alone (`po_tools.py`)** vs.
   * (b) **LLM-only / same-context self-review** vs.
   * (c) **PaperOEGM hybrid (`po_tools.py` + flat fresh-context read-only critics)** across realistic scientific integrity & security faults (synthetic `dry_run` leakage, subtle decimal transcription drift, unverified/hallucinated BibTeX keys, `git_dirty` flags, `.md`↔`.tex` conversion drift, double-blind `%`-comment/metadata leaks, Zip Slip & `\write18` template payloads, and Codex workspace tampering).
3. **Gap 3 — Cross-Harness Dispatch Portability & Context Economics:** Empirical measurement of skill loader token footprints (`<= 12 KB` vs. monolithic baselines), flat 1-level dispatch viability across Antigravity and Claude Code (where nested `synthesizer` topologies fail on read-only/Cowork hosts), and `po_tools.py` latency/determinism with zero external dependencies.
